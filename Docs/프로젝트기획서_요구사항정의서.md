# 화학물질 안전교육 VR 프로젝트 기획서

문서 버전: 1.0  
작성일: 2026-09-15  
프로젝트명: 화학물질 안전교육 VR  
팀명: Tyche  
팀 구성: 1인

## 1. 프로젝트 주제

Meta Quest 기반 가상현실 환경에서 화학물질 취급 작업 전 필요한 개인보호구(PPE) 선택·점검·착용 절차를 교육하는 체험형 안전훈련 애플리케이션을 개발한다.

## 2. 프로젝트 목표

교육생이 작업 조건에 맞는 보호구를 선택하고, 보호구의 상태를 점검한 뒤, 올바른 순서로 착용하는 과정을 가상현실에서 반복 학습할 수 있도록 한다. 교육·훈련·테스트 모드를 분리해 설명 수준과 평가 방식을 다르게 적용하고, 수행 결과를 세션 이벤트로 기록해 서버와 운영 대시보드에서 조회할 수 있도록 한다.

## 3. 대상 사용자

- 화학물질 취급 작업을 시작하기 전 안전교육을 받는 교육생
- PPE 선택과 착용 절차를 반복 훈련해야 하는 현장 작업자
- 교육 결과와 수행 이력을 확인하는 관리자

## 4. 요구사항 목록

### 4.1 필수 기능

| ID | 기능명 | 요구사항 |
|---|---|---|
| FR-01 | XR 초기화 및 씬 전환 | 앱 실행 후 타이틀·인트로·로딩을 거쳐 PPE Room에 진입한다. |
| FR-02 | 컨트롤러 조작 교육 | 이동, Ray 선택, Trigger, Grip 등 기본 조작을 단계별로 안내한다. |
| FR-03 | 작업계획 선택 | `ConfinedSpace`, `LeakResponse` 작업계획 중 하나를 선택한다. |
| FR-04 | 모드 선택 | `Education`, `Training`, `Test` 중 하나를 선택한다. |
| FR-05 | PPE 선택 및 잡기 | 위치 마커가 지정된 PPE를 직접 잡고 선택한다. |
| FR-06 | PPE 상태 점검 | 정상·불량 PPE를 구분하고 사용 또는 폐기 결과를 판정한다. |
| FR-07 | PPE 착용 | 방호복, 장갑, 장화, 호흡보호구, 안전모, 안전대를 착용 조건에 맞게 처리한다. |
| FR-08 | 착용 상태 확인 | 필수 PPE, 테이프 조건, 거울 확인을 완료해야 다음 단계로 진행한다. |
| FR-09 | 모드별 안내 | 교육은 상세 설명과 오류 교정, 훈련은 기본 지시, 테스트는 수행 결과 기록 중심으로 동작한다. |
| FR-10 | 퀴즈 및 결과 | 작업계획별 문항을 채점하고 점수, 정답 수, 오선택, 소요시간을 표시한다. |
| FR-11 | 세션 기록 | 세션 ID와 순번을 부여해 주요 상태·선택·오류·완료 이벤트를 기록한다. |
| FR-12 | 서버 전송 | 세션 생성, 이벤트 배치, 완료 요청을 HTTPS API로 전송한다. |
| FR-13 | 운영 조회 | 관리자가 사용자·플레이·세션 상세와 훈련 결과를 대시보드에서 조회한다. |
| FR-14 | 완료·종료 처리 | 정상 완료와 종료 사유를 구분해 세션을 종료하고 마지막 기록을 저장한다. |

### 4.2 선택 기능

| ID | 기능명 | 요구사항 |
|---|---|---|
| OR-01 | 한글 이름 입력 | 교육생 이름을 입력하고 세션 표시 정보에 연결한다. Alpha 운영에서는 우회 설정을 사용할 수 있다. |
| OR-02 | 음성 안내 확장 | 단계별 VOICE·SFX와 자막을 추가한다. |
| OR-03 | 손 모델 표현 | PPE 상태에 따라 손 모델과 시각 효과를 변경한다. |
| OR-04 | 관리자 알림 | 운영자에게 서버 알림·푸시 구독 상태를 제공한다. |

## 5. 포함 범위

- PPE Room 중심의 독립형 Meta Quest/OpenXR 체험
- `ConfinedSpace`, `LeakResponse` 2개 작업계획
- 작업계획별 Education·Training·Test 3개 모드
- PPE 선택·점검·폐기·착용·거울 확인·퀴즈·결과
- 클라이언트 로컬 JSONL 원본 기록
- HTTPS 기반 서버 전송과 DB 원본 저장
- 운영 대시보드의 사용자·플레이·세션 결과 조회

## 6. 제외 및 후속 범위

- 혼합기동 전체 밀폐공간 진입 절차
- 혼합기 내부의 사고 체험과 후속 VFX 시나리오
- LMS 자동 연동
- 다중 사용자 동시 체험
- 음성인식 기반 자유 대화
- 현장별 고객사 MSDS 자동 연계
