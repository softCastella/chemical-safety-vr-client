1차 교육모드약 5분PPE 7종

교육모드 기준 상세 튜토리얼 절차

순서교육 단계사용자 수행교육모드 안내·완료 조건
1작업정보 안내보이스 또는 텍스트로 작업 내용과 필요한 PPE 안내를 확인한다.안내가 1회 완료되면 PPE 진열장 위치 마커 활성화
2대상 이동오른손 Ray로 PPE 진열장 앞 위치 마커를 선택한다.텔레포트 페이드 후 현재 점검 대상 1개만 강조
3PPE 잡기·선택Grip으로 보호구를 잡고 현재 선택한 장비를 확인한다.선택한 PPE에만 사용·폐기 UI 활성화
4정상·불량 판정정상품은 Trigger(사용), 불량품은 A(폐기)로 선택한다. 판정하지 않고 취소하려면 Grip을 다시 눌러 놓는다.Trigger 사용 시 자동 착용 시작, A 폐기 시 정상품 재등장. 오판정은 이유 안내 후 재선택
5자동 착용·설명PPE가 사용자 앞/위에서 몸의 해당 착용 위치로 이동하며 완전히 착용되는 연출을 본다.입는 중 해당 PPE 착용 시 주의점을 보이스로 1회 설명
6착용 결과몸을 내려다보거나 거울을 통해 지금까지 착용한 PPE와 적용한 테이프가 몸에 표시되는 것을 확인한다.착용·적용된 PPE만 몸과 거울에 표시. PPE 7종 완료 시 자동으로 퀴즈 활성화

프로토타입에서 다루는 PPE

구분구현 대상프로토타입 표현
PPE 7종방호복, 장갑, 장화, 호흡보호구, 안전모, 등지게, 테이프6종의 장비 모델과 테이프 적용 상태를 구현하며, 테이프를 포함해 PPE 7종으로 계산한다.
상태 판정장갑·장화 2개 그룹정상/불량 프리팹, 찢김·오염 마커, 사용/폐기 후 정상품 재등장
(구현중 불량의 구현 종류와 표현, 등장 종류 정책이 바뀔 여지가 있습니다.)
착용 상태장갑·장화 좌우 + 나머지 4종 + 테이프좌우 상태와 테이프 적용 상태는 별도 저장. 몸을 내려다보거나 거울을 확인하면 실제 착용·적용 완료된 PPE만 표시
모드 확장 기준 · 위 절차와 완료 조건은 세 모드가 공유한다. 훈련모드는 기본 목표만 남기고 단계별 설명·대상 강조를 제거하며, 테스트모드는 모든 수행 안내를 숨긴 채 선택·오류·소요시간만 기록한다. 실제 교육판의 PPE는 MSDS와 위험성평가에 따라 다시 확정한다.
