# 2026-08-09 PPE Room HandTest 회의록

## 오늘 새로 추가·변경한 요소

| 요소 | 내용 |
| --- | --- |
| Game View Test Mode | Inspector 체크박스로 마우스·키보드 XR 시뮬레이터를 켜고 끌 수 있게 추가. 실제 Quest 테스트 시에는 OFF로 사용. |
| 장화 화학 오염 | 좌·우 장화에 방호복과 같은 불규칙 화학 얼룩 셰이더 적용. 검정 장화 위에서도 오염을 식별할 수 있게 구성. |
| 마스크 유리 균열 | 투명·양면 유리 소재 느낌의 청백색 균열 시각물 추가. |
| PPE 패널 피드백 | 사용/폐기 선택에 맞춰 각 버튼 위치에 성공·오류 아이콘이 표시되도록 정리. |
| 반복 테이핑 | 장갑·장화가 남아 있으면 테이프를 다시 사용할 수 있도록 변경. 이미 착용한 여러 짝은 한 번에 테이핑 가능하며, 마지막 짝까지 끝나면 테이프가 사라짐. |
| 마지막 PPE 안내 | 마지막 장비에는 “다음 PPE” 대신 장착 완료 뒤 거울 이동 안내가 이어지도록 변경. |
| 거울 완료 후 카드 | 복귀 뒤 시나리오 카드 Canvas와 카드 HUD를 함께 표시하도록 변경. |
| PPE 최종 퀴즈 | GitHub 퀴즈 작업본의 5문제 퀴즈 UI, 퀴즈 음성, 정답/오답 처리, 완료 복귀 흐름을 현재 씬에 통합. |
| 하자·정상 헬멧 교체 | 테이블 위 헬멧을 같은 로컬 Pose의 형제 `helmet_wrong`/`helmet`으로 분리. 처음에는 하자 헬멧만 표시하고, 올바른 폐기 후 하자를 비활성화한 뒤 끈이 달린 정상 헬멧을 활성화. |

## 최종 교육 흐름

`PPE 전체 착용 → 거울 관찰 → 퀴즈 안내 음성 → 5문제 퀴즈 → 수고했다 음성 → 시작 지점 복귀 → 시나리오 카드 표시`
