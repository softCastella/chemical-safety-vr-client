1. 제작 준비와 핵심 기능 구현

날짜별 작업 · 산출물 · 완료 기준
날짜핵심 작업구체 산출물완료 기준
08.01핸드 모델 애니메이션·에셋 기획서·3D 모델 정리좌·우 손 Idle·Grip·Trigger 애니메이션과 입력 전환, 에셋 기획서 수정본, 파일명·스케일·피벗·머티리얼을 정리한 모델 세트테스트 씬에서 손목 뒤틀림 없이 포즈가 전환되고 문서와 모델 정리가 완료된다.
08.02Unity 통합 점검·기준선 확정정리된 손·3D 모델 재임포트, Animator 파라미터, XR 입력 연결, 테스트 씬 기준 프리팹손과 모델이 정상 표시되고 XR 입력·머티리얼·참조·콘솔에 진행 차단 문제가 없다.
08.03공통 XR 입력·상호작용 기반Grip Toggle Grab, Trigger UI, A·B 문맥 입력, 공통 피드백 프리팹잡기·놓기·UI 선택·버튼 입력이 충돌 없이 동작한다. 버튼 배정은 개발·기기 테스트 과정에서 변경될 수 있다.
08.04PPE 대표 기능 수직 구현대표 PPE 1종, Grab·회전 점검, Trigger 사용·A 폐기 판정, 재Grip 취소(놓기), 착용 상태와 완료 UI작업정보 안내 후 대표 PPE의 점검·판정·착용과 오류 재시도를 처음부터 끝까지 수행한다.
08.05밀폐공간 전반부 구현태블릿 1대의 안전문서 전환·확인·서명, VR 컨트롤러 입력을 통한 제어반 전원 OFF와 LOTO 적용안내된 문서·전원·LOTO 절차를 완료하지 않으면 다음 단계로 진행하지 않는다.
08.06밀폐공간 후반부 구현한 번 측정으로 상·중·하부 전체 처리되는 1차 FAIL·2차 PASS, 덕트·환기, 무전·감시인 승인측정 → 환기 → 재측정 → 승인 순서가 선행조건과 함께 한 사이클로 동작한다.
08.07두 핵심 시나리오·공통 결과 연결PPE·밀폐공간 대표 수행, 공통 결과 화면, 허브 복귀와 상태 초기화두 핵심 시나리오가 수행 후 결과·복귀·재시작까지 연속 동작한다.

2. QA·발표·피드백 반영

시나리오별 약 5분 · 총 약 10분
날짜핵심 작업구체 산출물완료 기준
08.08Quest 2 실기기 QA·최적화Android APK, 실기기 입력·씬 전환·초기화 점검표, 성능 측정 기록과 수정 목록Quest 2에서 설치·실행·대표 흐름 완주가 가능하고 시연 차단 오류가 없다.
08.09시연 빌드 동결·리허설발표용 빌드 후보, 시나리오별 약 5분 순서표, 장비 체크리스트, 대체 영상 2개PPE와 밀폐공간 시나리오를 각각 약 5분 안에 앱 시작부터 결과까지 재현하고 발표용 파일을 동결한다.
08.10프로토타입 시연 발표Quest 2 실행 빌드, 2개 시나리오 시연 순서표, 대체 영상과 발표 피드백 기록두 시나리오를 각각 약 5분씩 총 약 10분 동안 시연하고 수정 우선순위를 확정한다.
08.11발표 피드백 분류·치명 오류 수정피드백 목록, P0·P1·P2 우선순위, 진행 차단·입력·씬 전환 결함 수정본프로토타입 완주를 막는 P0 결함이 없고 후속 작업 순서가 확정된다.
08.12교육모드 안내·퀴즈·초기화 보강상세 안내 UI, 대표 퀴즈, 결과 표시, 허브 복귀와 세션 초기화대표 수행 종료 후 퀴즈·결과·복귀·재시작이 연속 동작한다.
08.13교육모드 프로토타입 1차 완료Quest 2 실행 빌드, 프로토타입 QA 기록, 알려진 제한사항과 다음 개발 목록두 핵심 시나리오가 시작 → 수행 → 결과 → 초기화 한 사이클을 완주한다.
프로토타입 범위 · 8월 13일까지 교육모드의 공통 구조와 PPE·밀폐공간 두 핵심 시나리오를 구현한다. PPE는 테이프를 포함한 7종을 점검·판정·착용·적용하는 구조로 구현한다. 사고 체험은 후속 범위로서 완료 기준에서 제외하며, 핵심 범위 구현·QA가 조기 완료된 경우에만 제한형으로 추가한다. 훈련·테스트모드는 8월 14일 이후 확장한다.
