# 거울 관찰 게이지 미표시

## 상태

- 재현 확인
- 원인 확인 및 로코모션 씬 적용 완료
- Quest/OpenXR 실기 검증 대기

## 대상

- 씬: `Assets/Scenes/3_PPE_Room_Train_Test_mask_locomotion.unity`
- 현재 후속 씬: `Assets/Scenes/3_PPE_Room_3mode_loco.unity`
- 컴포넌트: `Assets/Scripts/PPEFinaleController.cs`
- 영향 기능: 거울 앞 5초 관찰 게이지

## 증상

거울 앞 관찰 위치에 도착해도 관찰 게이지가 표시되지 않는다.

## 확인 결과

- `PPEFinaleController`의 거울 관찰 지점, 거울 시선 대상, 게이지 루트 및 Fill 참조는 씬에 연결되어 있다.
- 게이지 Canvas는 활성 상태이고 게이지 루트만 시작 시 비활성인 작성값이다.
- `IsWithinMirrorRadius()`가 관찰 지점과 카메라의 수평 거리가 `0.0001`보다 작으면 `false`를 반환한다.
- 런타임에서 관찰 지점에 카메라를 정확히 겹친 경우 게이지가 표시되지 않았다.
- 같은 위치에서 수평으로 `0.2 m` 이동한 뒤 동일한 거울 도착 경로를 호출하면 게이지 루트가 활성화됐다.

## 근본 원인 후보

관찰 지점 중심을 유효한 반경 내부로 인정하지 않는 0 거리 예외 조건 때문에, 자동 텔레포트 또는 XR Origin 중심이 Marker와 정확히 겹칠 때 관찰 루틴이 중단된다.

## 영향 범위

- 거울 도착 후 관찰 게이지 시작
- 거울 관찰 완료 및 이후 퀴즈 전환
- 거울 Marker 도착 경로와 위치 기반 거울 진입 경로

## 적용한 변경

- `PPEFinaleController.IsWithinMirrorRadius()`에서 관찰 지점과 카메라가 정확히 겹칠 때 거부하던 0거리 예외를 제거했다.
- 로코모션 씬에서 `PPEVoiceTeleportEventRelay`를 비활성화하고 중심/거울 Marker 참조를 비웠다.
- 로코모션 씬의 `Markers/Teleport_1`, `Markers/Teleport_2` 그룹을 비활성화했다. 원본 `_mask` 씬은 변경하지 않았다.

## 아직 필요한 검증

- 관찰 지점 중심, 실제 HMD 오프셋, 거울 정면 위치에서 Unity Editor와 Quest/OpenXR 양안 재현을 확인한다.
- 수정 후 게이지 0% 시작, 5초 진행, 이동 이탈 시 중단 및 재진입 동작을 검증한다.

## 2026-08-26 로코모션 씬 후속

### 재현된 추가 원인

현재 로코모션 씬에서는 `PPEFinaleController`가 `WaitingForEquipment` 상태에서 PPE 완비 여부를
먼저 검사했다. 따라서 PPE가 하나라도 빠진 상태에서는 거울 관찰 상태로 들어가지 못했고, 작성된
게이지 참조가 정상이어도 게이지가 나타나지 않았다. 요구 동작은 거울 관찰을 먼저 수행하고 5초
관찰 뒤 부족 항목을 안내하는 순서다.

### 적용한 변경

- 활성 PPE 모드 세션이면 `WaitingForEquipment`에서 `WaitingForMirror`로 진입한다.
- 관찰 완료 뒤 기존 `HasPpeCompletionRequirements()`와 태블릿 완료 조건을 판정한다.
- 미완료 결과 뒤에는 손과 Ray를 다시 표시하고, 플레이어가 관찰 반경을 벗어난 뒤 재진입해야
  다음 관찰을 시작하는 기존 재무장 조건을 유지한다.
- 씬의 `m_XrOrigin`, 관찰 지점, 시선 대상, 게이지 루트와 Fill 참조 및 작성된 UI 값은 변경하지
  않았다.

### 검증 상태

- 정적 확인: 현재 씬의 거울 참조 5개와 5초 관찰 작성값을 확인했다.
- 정적 컴파일: Runtime/Editor 빌드 오류 0개이며 기존 deprecated API 경고만 남아 있다.
- Unity Play Mode와 Quest/OpenXR에서는 PPE 미완료·완료 양쪽의 게이지 표시, 이탈, 재진입,
  양안 표시를 아직 확인해야 한다.

## 2026-08-27 후속: 시선 이탈 시 관찰 게이지 정지 제거

- 기존 관찰 루틴은 플레이어가 반경 안에 있어도 `IsLookingAtMirror()`가 참일 때만 5초 게이지를
  증가시켰다. 사용자는 고개를 돌렸을 때 진행이 멈춘 사실을 알아채기 어려웠다.
- 거울 관찰이 시작된 뒤에는 시선 방향과 무관하게 게이지가 계속 증가하도록 변경했다.
- 작성된 관찰 반경을 벗어나면 관찰을 중단하고 재진입을 요구하는 거리 조건은 유지했다.
- Unity Editor 정적 검증에서 시선 조건 제거, 무조건 시간 증가, 반경 이탈 중단 경로가 PASS했다.
- Quest/OpenXR에서는 고개 돌림 중 연속 진행과 실제 반경 이탈 중단을 수동 확인해야 한다.
