## 적용한 변경

### v9 데이터 마이그레이션

- v10 전용 저장 데이터가 없을 때만 v9의 IndexedDB와 Local Storage를 조회한다.
- v9에서 찾은 내용을 v10 저장 영역으로 복사한다.
- v9 저장 영역에는 쓰지 않아 원본 데이터를 보존한다.

### 3-1 반복 초기화 제거

- 3-1의 34개 행 재생성은 v9 데이터를 최초 마이그레이션하는 경우에만 실행한다.
- v10 저장 내용, JSON 복원 내용과 HTML 저장본 내장 내용에는 구조 변환을 반복
  적용하지 않는다.

### HTML 저장본 격리

- 저장본 루트에 `data-standalone-snapshot="true"`를 기록한다.
- 저장본마다 고유한 저장 키를 생성한다.
- 저장본은 v9 레거시 저장 영역을 조회하지 않는다.
- 현재 DOM의 텍스트와 Base64 이미지를 저장본 HTML에 직접 포함한다.

### 편집·열람 모드 분리

- 편집본은 텍스트, 표, 스크린샷과 5-1 이미지 편집 기능을 유지한다.
- 저장본은 편집 초기화를 건너뛰고 편집 도구와 이미지 수정 UI를 숨긴다.
- 저장본 이미지 클릭·터치는 전체 화면 확대 보기로 연결한다.
- 확대 화면은 배경, `닫기`, `Esc`로 종료한다.

### 5-1 동적 행 이미지 셀 복구

- 일반 셀은 새 행 생성 시 기존처럼 비우고 편집 가능 상태로 만든다.
- `.asset-image-cell`은 일반 셀과 분리해 이미지 미리보기, 첨부, 해제와 붙여넣기 안내
  구조를 새로 구성한다.
- 이미 저장된 35번째 행처럼 이미지 셀 구조가 비어 있는 경우에도 페이지 초기화 시
  필요한 구조를 자동 복구한다.
- 기존 이미지가 들어 있는 정상 셀은 다시 만들지 않아 첨부 이미지를 보존한다.

### 단순 순번형 No 셀 복구

- 첫 번째 헤더가 `No`이고 기존 값이 모두 단순 숫자인 표만 자동 채번 대상으로 삼는다.
- 새 행 추가 직후 빈 `No` 셀에 기존 번호와 겹치지 않는 다음 번호를 입력한다.
- 페이지 초기화 시 이미 저장된 빈 번호를 복구하고, 변경이 있으면 자동 저장한다.
- 저장용 DOM을 만들기 직전에도 빈 번호를 검사해 편집용 이동 손잡이 제거 후 번호만
  사라지는 문제를 차단한다.
- 기존 `01~34` 번호와 사용자 작성 셀은 유지한다.
- `05·06 PPE 진열장`처럼 숫자 외 설명이 들어간 `No` 표는 자동 채번하지 않는다.
