교육모드 · 상세 지원

  • 작업정보와 필요한 PPE를 보이스·텍스트로 설명
  • 현재 점검 대상·결함 위치·입력 버튼을 강조
  • 오판정 시 “손상된 장갑은 폐기” 이유 안내
  • 올바른 정상품을 다시 제공하고 착용까지 유도

훈련·테스트모드 · 후속

  • 훈련: “PPE 7종 점검·착용” 기본 목표만 표시
  • 훈련: 결함 위치·판정 정답·다음 대상 강조 없음
  • 테스트: 목표 외 수행 지시와 즉시 정오답 없음
  • 테스트: 첫 선택·오판정·누락·완료시간 결과화

교육모드 1차 완료 판정(Definition of Done)

작업정보 보이스·텍스트 안내 완료 전 PPE 단계로 건너뛸 수 없다.
장갑·장화 정상/불량 판정이 결과와 일치한다.
오판정 후 실패 종료 없이 같은 항목을 재시도한다.
gloveL/R, bootL/R가 각각 독립적으로 저장된다.
자동 착용 중 해당 PPE 착용 시 주의점 VOICE가 한 번 재생된다.
몸을 내려다보거나 거울을 확인할 때 착용 완료된 PPE만 보인다. PPE룸 조명과 전신 거울은 필수로 유지한다.
테이프를 포함한 PPE 7종 완료 후 5문항 퀴즈·해설이 열린다.
완료 후 허브 복귀 시 PPE와 점수가 초기화된다.

모든 PPE의 결함 분기장갑·장화에서만 대표 결함을 검증하고 구조 재사용 가능하게 제작

시연 핵심 장면 · 교육모드에서 손상 장갑을 Trigger(사용)로 오판정 → 이유 안내 → A(폐기)·정상품 재등장 → Trigger(사용) → 자동 착용 → 착용 시 주의점 VOICE까지 연결한다. 판정 전 재Grip은 취소(놓기)로 처리한다. 훈련·테스트모드 추가 시 같은 상태 전이를 유지하고 안내만 단계적으로 제거한다.
