프로토타입 목표·완료 정의

최종 운영안은 각 상세 시나리오를 교육·훈련·테스트 3모드로 제공하는 것이다. 다만 1인 개발과 8월 13일 마감을 고려해, 이번 단계에서는 두 시나리오의 절차·상호작용·판정과 상세 안내를 포함한 교육모드를 먼저 완성한다.

2개완주 가능한 교육 시나리오
3모드교육 → 훈련 → 테스트 확장
1차상세 튜토리얼형 교육모드
0건시연 차단 P0 결함 목표

1차 구현 · 교육모드

  • PPE와 밀폐공간 시나리오의 처음-끝 완주
  • 단계별 목표·입력법·대상 위치 상세 안내
  • VOICE·자막·하이라이트·위치 마커 동기화
  • 오조작 이유 설명, 올바른 행동 제시, 재시도
  • 퀴즈·해설·결과·초기화와 Quest 2 실행

후속 구현 · 모드 확장

  • 2차 훈련모드: 목표와 기본 지시만 제공
  • 상세 튜토리얼·정답 유도·대상 강조 제거
  • 3차 테스트모드: 수행 중 지원 UI·음성 없음
  • 도움 없이 수행한 순서·오류·시간·결과 기록
  • 공통 시나리오 상태와 완료 조건은 그대로 재사용

모드별 구현 순서와 완료 기준

단계모드지원 수준다음 단계 진입 조건
1차교육모드상세 튜토리얼·오류 교정·퀴즈 해설두 시나리오 P0 0건, Quest 2 2회 연속 완주
2차훈련모드현재 목표와 기본 지시만 제공교육모드 회귀 이상 없이 기본 지시만으로 완주
3차테스트모드수행 중 도움 없음, 종료 후 결과만 제공가이드 노출 0건, 수행 기록·채점 검증 완료
범위 유지 원칙 · 모드 확장은 안내 수준을 분리하는 작업이며 시나리오 절차 자체를 다시 만들지 않는다. 사고 체험·혼합기 내부 청소·서버 연동과 사실적 물리는 세 모드 공통으로 이번 프로토타입 범위에서 제외한다.
