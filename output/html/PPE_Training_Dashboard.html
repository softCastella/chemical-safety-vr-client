이 화면의 단위 콘텐츠(PPE)별 수행도입니다. 모드별 수행도는 “학습 · 수행 분석” 화면에서 별도로 봅니다. 사용자 범위를 전체로 하면 30명 집계, 특정 사용자를 고르면 해당 사용자의 기록만 계산합니다.

사용자 상세의 범위

사용자 상세는 한 사용자의 여러 회차를 연결해 학습곡선·오류 재발·자력 수행률을 보는 화면입니다. 전체 사용자의 평균은 이 화면이 아니라 전체 개요·콘텐츠 비교에서 확인합니다.

현재 상단 범위를 사용자 A로 바꾸면 모든 화면의 KPI와 표가 사용자 A 기준으로 재계산됩니다.
